# sample-openai-examples

Some examples for OpenAI APIs.

## install

npm install

## examples

Various JavaScript files in examples folder. They show different API
features. You can run them with node.

For chat: `node examples/01-basic-chat.js`
Streaming is in 02. Function calling 03. Vision 04. Embeddings 05.

## env

Set OPENAI_API_KEY first.
